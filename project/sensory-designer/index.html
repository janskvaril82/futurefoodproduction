How the designs are made

  • Triangle test: the six arrangements ABB, AAB, ABA, BAA, BBA and BAB are used equally often, in random order within each group of six panellists (ISO 4120:2021). Every cup gets its own random three-digit code, so the two identical samples cannot be recognised by their codes.
  • Hedonic rating: Williams Latin squares (Williams, 1949): the first sequence alternates from the ends of the sample list (0, 1, t−1, 2, t−2, …), each further sequence adds one to every entry (mod t), and for an odd number of samples the mirror images are added. Every sample appears equally often in every position and follows every other sample equally often (MacFie et al., 1989; Lesson 13.4). Complete sets of sequences are allocated to panellists in random order.
  • Paired preference: the orders AB and BA are balanced within each pair of panellists.
  • Codes: random numbers from 100 to 999 without repeated digits and without runs such as 123 or 987; with “new codes for every panellist” each tray gets its own codes.

Statistics

  • Triangle: one-sided exact binomial test with p₀ = 1/3, proportion of discriminators pd = (3pc − 1)/2 with a normal-approximation 95 % CI, and Thurstonian d′ from the triangle psychometric function (Eqs. 13.4.2–13.4.4).
  • Hedonic: randomised-block ANOVA with panellists as blocks, Tukey's HSD for all pairs (tukeyRCBD), partial η²; panellists with missing ratings are left out of the ANOVA.
  • Preference: two-sided exact binomial test with p₀ = 1/2 and a Wilson 95 % CI of the proportion.

Format

Stored in this browser under the key ffp-sensory-v1 and read by the triangle-test and hedonic-analysis laboratories:

{ "version": 1,
  "design": { "test": "triangle" | "hedonic" | "preference",
              "samples": [ { "code": "A", "label": "Wheat bread" }, { "code": "B", "label": "Cricket bread 10 %" } ],
              "panellists": 24,
              "orders": [ ["A","B","B"], ["B","A","A"], … ],        // sample codes in serving order, one array per panellist
              "codes":  [ ["583","214","796"], … ],                  // three-digit cup codes, same shape (extra)
              "title", "seed", "uniqueCodes", "created" },          // extras
  "responses": [ { "panellist": 1, "correct": true, "chosen": "796" } ]            // triangle
             | [ { "panellist": 1, "sample": "A", "score": 7 } ]                    // hedonic (one per sample)
             | [ { "panellist": 1, "sample": "B", "score": 1 } ] }                  // preference: the preferred sample

Panellists are numbered 1…n in the order of the serving plan. The responses CSV (long format: panellist, position, code, sample, label, score / correct) can be pasted into the statistics workbench for a randomised-block ANOVA with panellists as blocks.
