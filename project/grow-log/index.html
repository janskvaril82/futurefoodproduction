Grow log

The data home of your growing experiment. Define the experiment once, then enter the daily solution readings, the weekly growth measurements, the harvest and your water and electricity records. The log checks every value as you type, draws every variable by treatment and calculates relative growth rates, water use per plant and day and cumulative electricity. Everything stays in this browser — export after every session.

Key indicators of your system

Calculated from the harvest rows, the system log and the set-up. Definitions follow Lesson 8.4; the worked calculations are in the analysis guide.

Relative growth rate between measurement dates

RGR = (mean ln W₂ − mean ln W₁)/(t₂ − t₁) per treatment (Hoffmann & Poorter, 2002), with the standard error of the individual plants' RGRs; doubling time = ln 2/RGR (Lesson 2.4).

RGR over time

Mean RGR ± SE in each interval, plotted at the interval midpoint.

Harvest summary

Area → fresh-mass calibration

Power law FW = a·Ab fitted on log–log axes to all rows with both values (Eq. 2.4.10).

Water use

Water used per plant and day = water used ÷ plants in the container ÷ days between readings.

Electricity

Cumulative consumption from the energy-meter readings, compared with lamp power × photoperiod × days.

Quality check

Automatic checks of ranges, targets, duplicates, falling growth values, energy-meter readings and missing measurements. A warning is not an error: investigate it, correct typing errors and describe real events in the notes (data-quality rules).

    How to use the grow log

    1. Set-up (once): title, crop, system and the start date (day 0 = transplanting); treatments with optional target EC; the plant list with containers and blocks.
    2. Every measurement session: Enter data → choose the date and the variable groups → type the values → Save. Add water, energy-meter and climate readings to the system log.
    3. After every session: open Quality check, fix typing errors, then Export CSV and Backup (JSON) into your group folder.
    4. Analysis: Charts and Growth & resources give a first look; the laboratories below read the same data directly from this browser.

    Where the data go

    The log is stored only in this browser under the key ffp-growlog-v1. These laboratories can load it with one click: growth-curve model fitting, statistics workbench, crop growth model and the plant-vision lab. Your progress includes the log in its backup file.

    Format

    { "version": 1,
  "meta": { "title", "crop", "system", "startDate": "YYYY-MM-DD", "treatments": [ … ],
            "group", "plants": [ { "id", "treatment", "unit", "block" } ], "targets": { "EC 1.6": { "ec": 1.6 } },
            "photoperiod_h", "area_m2", "lamp_w" },
  "rows": [ { "date", "day", "plant", "treatment", "fw_g", "leaves", "area_cm2", "height_cm",
              "ec", "ph", "t_water", "do_mgl", "ppfd", "notes", "dw_g"?, "root_fw_g"? } ],
  "resources": [ { "date", "unit", "water_l", "kwh", "air_t", "rh", "notes" } ] }

    The first four meta fields and the fourteen row fields are the course standard; everything else is optional and ignored by tools that do not use it. CSV exports use the same column names (plus unit and block from the plant list, and dw_g, root_fw_g when present). The CSV import accepts comma, semicolon or tab separators, decimal commas, ISO dates and common alternative column names (e.g. DAT, fresh_weight, area); a file with water_l or kwh but no plant column is imported into the system log. See the templates and data dictionary.

    Units

    fw_g, dw_g, root_fw_g in g · area_cm2 in cm² · height_cm in cm · ec in mS cm⁻¹ compensated to 25 °C · t_water in °C · do_mgl in mg L⁻¹ · ppfd in µmol m⁻² s⁻¹ · water_l in L · kwh cumulative meter reading in kWh · air_t in °C · rh in %.

    Privacy

    Nothing is uploaded. Do not put personal data (names of panellists, health information) in the notes — the grow log is for plants.
