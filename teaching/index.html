Teacher's guide

Running Future Food Production

This guide explains how the online material, the physical laboratory sessions and the course project fit together over ten weeks, what equipment is needed, how learning outcomes are assessed, and how to keep the course current as technologies change.

Course design in one page

The course is built on constructive alignment: each learning outcome (LO1–LO7) is developed in specific modules, practised in laboratories and the problem generator, and assessed in the project report, laboratory assignments and the written examination (see the outcome matrix). Students meet every important idea in four forms:

  1. Lesson — narrative, derivations in equation boxes, worked examples and a self-marking quiz (≈ 40–65 min each).
  2. Laboratory — an interactive model of a real system with guided investigation tasks (≈ 30–60 min each).
  3. Practice — randomised problems with worked solutions and spaced repetition, until the calculations become automatic.
  4. Project — the same ideas applied to the students' own growing system and sensory study.

Weekly teaching plan

The schedule on the course page assumes a half-time, 7.5-credit course over ten weeks (≈ 20 h student work per week). A typical week contains one 2-hour seminar, one 3-hour laboratory session and supervised project time.

Safety

Keep electrical equipment above water level and use residual-current devices (RCD/GFCI). Wear gloves and eye protection when handling concentrated nutrient stocks and acids; never mix stock A and B concentrates. Keep grow lights out of direct line of sight. For the sensory study, only serve foods that are legally on the EU market, declare all allergens, obtain informed consent and keep responses anonymous — see the sensory study guide.

Assessment

The course page lists a suggested examination design (project report and presentation; laboratory assignments; written examination). The project rubric maps criteria to learning outcomes. For laboratory assignments, ask students to submit their saved investigations (the "Save investigation" button copies settings, results and a shareable link into their notebook, which they can export as Markdown).

The problem generator doubles as a formative question bank: each problem type exists in unlimited numerical variants with worked solutions, so it can be used for seminar exercises and to calibrate exam questions. The Exam mode gives students a timed set of ten problems without hints.

Using the virtual laboratories in class

  • Predict–observe–explain. Before moving a slider, ask students to predict the result (e.g., "what happens to PPFD under the fixture if we double the height?"), then observe and explain with the equation from the Derive tab.
  • Shareable states. Every setting is stored in the URL. Paste a link into the slides or the learning platform to start everyone from the same scenario.
  • Investigation tasks. Each lab ends with open tasks and a quiz; use them as seminar group work or as graded lab assignments.
  • Model limitations. Every lab lists its assumptions and sources. Asking "where would this model fail?" is an excellent examination question.

Keeping the course current

The syllabus states that the selection of technologies is continuously renewed. The site is designed for that:

  1. Structure — modules, lessons, laboratories, learning outcomes and the schedule live in one file, assets/js/course-data.js. Navigation, catalogues, progress tracking and search update automatically.
  2. Frontiers radar — review /frontiers/ each term: move technologies between rings, add milestones with sources, and retire what has stalled.
  3. Lessons — each lesson is a single HTML file following the authoring guide (docs/AUTHORING.md in the repository). Regulatory and market facts are marked "as of 2026"; check these first when updating.
  4. Reference pages — the equation book, glossary and bibliography are generated automatically from the lessons, so they never go out of date.
  5. Deployment — commit to the GitHub repository; Vercel redeploys automatically.

Accessibility and inclusion

All lessons work with keyboard and screen readers; the 3D laboratories have 2D charts, readouts and text explanations covering the same content, so no learning outcome depends on seeing a 3D scene. Students can study entirely offline from printed lessons (use "Print lesson"). See the accessibility statement.
